# 자두 🍑 — 자주 가는 곳을 두다

**자두**는 **자**주 가는 곳을 **두**다의 줄임말이에요.
(‘당근’이 ‘당신 근처’의 줄임말인 것처럼요.)

방송 맛집·빵집·카페·디저트·주차장 같은 **장소를 찾고 → 내 목록에 두고 → 길찾기로 이동**까지 한 번에 이어 주는 웹앱입니다.
GitHub Pages(무료)로 올리고, 휴대폰 홈 화면에 앱처럼 설치해서 씁니다. 홈 화면 아이콘은 위치 핀이 들어간 자두 열매예요.

- 앱 주소: <https://younguk06-sonny.github.io/myeongso/>

## 2. GitHub Pages로 올리기 (처음 한 번, 약 10분)

### 2-1. 저장소(Repository) 만들기
1. PC 브라우저에서 <https://github.com> 로그인 (계정: `younguk06-sonny`)
2. 오른쪽 위 **＋** → **New repository**
3. 입력
   - **Repository name**: `myeongso` (영어 소문자 권장. 이 이름이 주소가 됩니다)
   - **Public** 선택 ← 무료 GitHub Pages는 Public이어야 해요
   - 나머지는 건드리지 않아도 됨
4. 아래 초록 버튼 **Create repository**

### 2-2. 파일 올리기
1. 받은 `myeongso.zip`의 **압축을 먼저 풉니다** (zip 그대로 올리면 안 돼요)
2. 방금 만든 저장소 화면에서 **uploading an existing file** 링크 클릭
   (또는 **Add file → Upload files**)
3. 압축 푼 폴더 **안의 파일 9개를 전부 선택**해서 브라우저 창으로 끌어다 놓기
   - 폴더째가 아니라 *파일들*을 올려야 `index.html`이 맨 바깥에 놓여요
4. 아래 **Commit changes** 클릭 → 업로드 완료

### 2-3. Pages 켜기
1. 저장소 위쪽 메뉴 **Settings** → 왼쪽 메뉴 **Pages**
2. **Build and deployment**
   - Source: **Deploy from a branch**
   - Branch: **main** / **/(root)** 선택 → **Save**
3. 1~3분 기다린 뒤 새로고침하면 위쪽에
   `Your site is live at https://younguk06-sonny.github.io/myeongso/` 가 표시됩니다.
4. 그 주소가 내 앱 주소입니다. 휴대폰 카톡 '나와의 채팅'에 보내 두면 편해요.

> 진행 상황은 저장소의 **Actions** 탭에서도 볼 수 있어요. 초록 체크 ✅ 가 뜨면 배포 완료.

## 3. 휴대폰 홈 화면에 설치 (아이콘 생성)

**갤럭시(크롬)**
1. 크롬으로 앱 주소 열기
2. 오른쪽 위 **⋮** → **홈 화면에 추가** (또는 **앱 설치**) → **설치**
3. 홈 화면에 자두 열매 아이콘 ‘자두’가 생깁니다

**갤럭시(삼성 인터넷)**: 아래 **≡** → **현재 페이지 추가** → **홈 화면**

**아이폰(사파리)**: 아래 **공유 버튼(□↑)** → **홈 화면에 추가** → **추가**

설치 후에는 주소창 없이 앱처럼 전체 화면으로 열려요.

## 4. 사용법

### 📊 한눈에 탭 (첫 화면)
- 저장한 명소 수, 가본 곳·가볼 곳과 방문율
- 지금 반경 안에 있는 저장 명소 수와 가장 가까운 곳
- 테마별 저장 현황 막대그래프, 가까운 저장 명소 TOP 5
- 저장 목록에서 **☐ 가봤어요**를 누르면 방문 완료로 집계돼요

### 🔎 찾기 탭
1. **지역** 입력(예: `부천`, `성수동`) 또는 **📍 내 위치** 누르기
2. **테마** 누르기 (전현무계획, 로또 명당 …)
3. 뜨는 창에서
   - **네이버지도 / 카카오맵** → 지도에서 ‘부천 전현무계획 맛집’ 검색 결과가 열림
   - **네이버 통합검색·블로그·유튜브** → 실제 방송에 나온 집인지 확인
   - 로또 명당은 동행복권·1등 판매점 모음 링크도 같이 보여 줘요
4. 마음에 드는 곳은 **＋ 찾은 장소 저장하기**

**테마 편집**: ‘편집’ → 테마를 누르면 수정, ✕로 삭제, ‘테마 추가’로 새 테마
(예: 허영만 백반기행, 성시경 먹을텐데, 생생정보, 캠핑장, 아이랑 갈 곳 …)

### ⭐ 저장 탭
- 내가 저장한 장소 목록. 테마별로 걸러 보고, 최근순·이름순·가까운순 정렬
- 각 장소에서 네이버/카카오 바로 열기, 길찾기, 메모 수정

### 🗺️ 지도 탭
- 앱 안에서 **카카오맵**으로 실제 지도를 보여줘요. 내 위치(파란 점), 반경 원, 저장한 명소(★ 핀)가 표시돼요.
- 검색하면 결과가 지도 위 번호 핀으로 찍혀요.
- 핀을 누르면 **카카오맵 / 네이버지도** 앱(또는 웹)으로 열 수 있어요.
- 네이버 지도 화면을 앱 안에 넣는 기능은 **요금이 생길 수 있어서 넣지 않았어요.** 네이버는 '열기' 링크로만 써요 (무료).
- 카카오맵을 불러오지 못하면 자동으로 기본 지도(OpenStreetMap)로 보여줘요.

### 🅿️ 주차장 (찾기 → 기타 → 주차장, 또는 지도 탭의 🅿️ 버튼)
- 내 위치(또는 입력한 지역) 반경 안 주차장을 가까운 순으로 보여줘요.
- **1시간 요금**: 기본·추가 요금으로 계산한 값이에요 (1일 주차권보다 비싸면 1일권 금액). 무료만·공영만 보기, 1시간 요금순 정렬 가능.
- 오늘 운영시간, 주차면수, 기본/추가/1일/월정기 요금, 카카오맵·길찾기 버튼.
- 출처: 공공데이터포털 **전국주차장정보표준데이터**. 지자체가 올린 정보라 실제와 다를 수 있어요.
  일부 지자체(예: 부천시)는 요금 금액을 올리지 않아 '요금 정보 없음'으로 나와요.
- 데이터는 `parking/` 폴더에 있고, **매월 5일 GitHub Actions가 자동으로 새로 받아 갱신**해요 (무료).
  저장소 **Actions → update-parking → Run workflow** 로 바로 갱신할 수도 있어요.
  ※ GitHub은 저장소에 60일 동안 아무 변경이 없으면 예약 작업을 멈춰요. 멈췄다는 메일이 오면 Actions 화면에서 다시 켜 주세요.

### ⚙️ 설정
- **화면 모드**: 라이트(기본) / 다크 / 자동
- **링크 열기 방식**: 웹 / 지도 앱 (앱 방식은 네이버지도·카카오맵 앱 설치 필요)
- **카카오 JavaScript 키** 입력
- **백업 받기 / 불러오기**: 저장 장소·테마를 파일로 보관

> 💾 저장한 장소는 **그 휴대폰의 브라우저 안에만** 저장됩니다(서버에 올라가지 않음).
> 폰을 바꾸거나 브라우저 데이터를 지우기 전에 꼭 **백업 받기**를 해 두세요.

## 5. (선택) 카카오 지도 키 발급 — 앱 안에서 지도 보기

키 없이도 앱은 모두 동작합니다. 앱 안 지도를 쓰고 싶을 때만 하세요. 무료입니다.

1. <https://developers.kakao.com> 접속 → 카카오 계정 로그인
2. **내 애플리케이션 → 애플리케이션 추가하기**
   - 앱 이름: `자두` (예전 이름으로 만들었어도 상관없어요), 회사명: 본인 이름 → 저장
3. 만든 앱 → **앱 키**에서 **JavaScript 키** 복사
4. **플랫폼(또는 JavaScript SDK 도메인) → Web 사이트 도메인 등록**에
   `https://younguk06-sonny.github.io` 입력 후 저장
   - 주소 끝의 `/myeongso`는 넣지 않습니다
5. 메뉴에 **카카오맵** 사용 설정이 보이면 **ON(사용)** 으로 켜기
6. 휴대폰 앱에서 **⚙️ 설정 → 카카오 JavaScript 키**에 붙여넣고 저장

지도가 안 뜨면 대부분 ④ 도메인 등록이나 ⑤ 사용 설정 문제예요.
(카카오 화면 메뉴 이름은 가끔 바뀌니 비슷한 이름을 찾으면 됩니다.)

## 6. 앱을 고치고 다시 올릴 때

1. 저장소에서 바꿀 파일 클릭 → 연필(✏️) 아이콘으로 직접 수정 → **Commit changes**
   또는 **Add file → Upload files**로 같은 이름 파일을 다시 올리면 덮어쓰기
2. `sw.js` 맨 위 `myeongso-v1`의 숫자를 하나 올리기 (`v2`, `v3`…)
3. 1~3분 뒤 휴대폰에서 앱을 껐다 켜면 반영 (안 되면 한 번 더 껐다 켜기)

**기본 테마 바꾸기**: `index.html`에서 `DEFAULT_THEMES` 부분을 수정
- `em`: 아이콘 이모지, `name`: 버튼 이름, `kw`: 지역 뒤에 붙을 검색어
- 이미 앱을 쓰던 폰은 **설정 → 테마를 기본값으로 되돌리기**를 눌러야 새 기본값이 보여요
  (앱 화면에서 직접 테마를 추가·편집하는 게 더 쉬워요)

## 7. 알아두면 좋은 점

- 이 앱은 방송 맛집 목록을 **따로 보관하지 않고**, 네이버·카카오 검색으로 연결해 줍니다.
  그래서 항상 최신 정보가 나오지만, 검색 결과 중 실제 방송 출연 여부는 블로그·유튜브로 한 번 확인하는 게 좋아요.
- 카카오 앱 지도 검색은 **가게 이름·업종**으로만 찾아요. ‘전현무계획’ 같은 방송명은 거의 안 잡히니,
  방송 맛집은 네이버로 찾은 뒤 **장소 직접 추가 → 위치 찾기**로 저장하는 흐름이 가장 편합니다.
  로또 명당 테마는 앱 지도에서 ‘복권판매점’으로 검색돼요.
- 동행복권 공식 사이트는 예전의 ‘역대 1등 배출점 순위’ 메뉴를 없앴어요. 그래서 공식 사이트와 민간 모음 사이트를 함께 연결해 두었습니다.
